# DesiFit site information architecture

## Goal
Mobile-first curation site for India fashion traffic. Visitors browse curated looks and click Admitad deep links to Bewakoof, BlissClub, and Salty product pages.

## Routes
| Path | Purpose |
|------|---------|
| `/` | Brand hero + 3 main categories + featured looks |
| `/categories` | All categories & subcategories |
| `/categories/[category]` | Category overview + subcategory cards |
| `/categories/[category]/[subcategory]` | 10-look lookbook grid |
| `/looks/[id]` | Look detail with shoppable item deep links |
| `/disclosure` | Affiliate disclosure |
| `/privacy` | Privacy policy |
| `/contact` | Contact |

## Data
- Single source: `src/data/looks.json` (90 looks, Admitad-wrapped URLs, merchant images)
- Generated by `scripts/build-catalog.mjs`
