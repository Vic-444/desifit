# DesiFit

Curated Indo-Western, desi casual, and accessory lookbooks for [desifit.com](https://desifit.com).

## Stack

- Astro + Tailwind CSS v4
- Static deploy via Cloudflare Pages (GitHub)
- Admitad affiliate deep links (Bewakoof, BlissClub, Salty)

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run catalog` | Rebuild `src/data/looks.json` from curated catalog script |
| `npm run dev` | Local dev server |
| `npm run build` | Production build to `./dist` |
| `npm run preview` | Preview production build |

## Content

Look data lives in `src/data/looks.json` (generated by `scripts/build-catalog.mjs`).
Strategy notes are in `/docs`.
